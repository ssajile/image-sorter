# Image Sorter (이미지 분류기)

이미지를 편리하고 빠르게 분류할 수 있는 GUI 프로그램입니다.

## 주요 기능

- **소스 폴더 가져오기**: 지정한 소스 폴더의 이미지를 대기소로 이동(잘라내기)
- **프로젝트 단위 관리**: 프로젝트 이름으로 격리하여 여러 작업 병행 가능
- **1:1 화면 분할**: 왼쪽(선별소) / 오른쪽(대기소) 레이아웃
- **드래그&드롭 / 버튼 클릭**으로 이미지 이동
- **썸네일 그리드** 미리보기
- **폴더 트리** 탐색
- **작업완료**: 선별소 파일을 출력 폴더로 이동, 대기소 잔여 파일 삭제

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python main.py
```

## 사용 방법

1. **설정** (옵션 > 설정): 소스 폴더 경로와 출력 폴더 경로를 지정합니다.
2. **가져오기** 버튼: 프로젝트 이름 입력 후 소스 폴더의 이미지를 대기소로 이동합니다.
3. 오른쪽 대기소에서 이미지를 클릭하여 선택한 후 **선별소로 이동 →** 버튼을 누르거나, 왼쪽 선별소 영역으로 드래그합니다.
4. 작업이 끝나면 **작업완료** 버튼을 눌러 선별소의 파일을 출력 폴더로 이동하고, 대기소 잔여 파일을 삭제합니다.

## 폴더 구조

```
image-sorter/
├── main.py                 # 엔트리포인트
├── requirements.txt        # 의존성 (PySide6, Pillow)
├── config/
│   └── settings.py        # 설정 관리 (JSON 저장)
├── core/
│   ├── file_manager.py    # 파일 이동/삭제 로직
│   └── project_manager.py # 프로젝트 생성/관리
├── ui/
│   ├── main_window.py     # 메인 윈도우
│   ├── settings_dialog.py # 설정 다이얼로그
│   ├── project_dialog.py  # 프로젝트 이름 입력 다이얼로그
│   ├── staging_panel.py   # 대기소 패널 (오른쪽)
│   └── selected_panel.py  # 선별소 패널 (왼쪽)
└── data/                  # 프로그램 데이터 (자동 생성)
    ├── staging/           # 대기소
    ├── selected/          # 선별소
    └── settings.json      # 설정 파일
```

## 기술 스택

- Python 3
- PySide6 (Qt GUI 프레임워크)
- Pillow (이미지 썸네일 처리)
